# Vivid — Digital marketing agency

A responsive, single-page React website built with Vite. Includes service accordions, a Pinnacle Montessori client feature, agency values, FAQs, mobile navigation, and a project-brief planner.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The build is output to `dist/`.

## Contact planner

The planner validates fields and downloads a project brief as a text file. It does not send or store enquiries. Connect an approved contact address or form backend before using it to collect leads.

The Pinnacle Montessori logo uses the supplied brand artwork in `public/pinnacle-montessori-logo.jpg`. No performance statistics or testimonials have been invented.
